## image-studio：Vue3 SPA → Vite SSG 预渲染（SEO 改造收尾 + 门禁）

目标：每个工具是独立静态页面且 SEO 友好。决策（用户 AskUserQuestion 选定）：Vite SSG 预渲染 + 无尾斜杠 URL。

### 本次完成的关键修复
1. **headConfig.js 翻译函数 bug**：组合式 `createI18n({legacy:false})` 的翻译函数挂在 `i18n.global.t`，旧代码 `i18n.t.bind(i18n)` 在 SSR 渲染期 `TypeError` 致构建崩溃。改为 `i18n.global.t.bind(i18n.global)`。
2. **Element Plus SSR provider**：在 `src/main.js` 的 ViteSSG 回调里 `app.provide(ID_INJECTION_KEY, {prefix:1024,current:0})` 与 `ZINDEX_INJECTION_KEY`，消除 IdInjection/ZIndexInjection 警告并避免 hydrate 不匹配。
3. **vite-ssg 不枚举动态段**：默认 `includedRoutes` 不会展开 `:locale`，只渲染了根路由。在 `vite.config.js` 的 `ssgOptions.includedRoutes()` 里显式枚举「语言×工具」全部路径（9 语言×(1 首页+12 工具) + 根 = 118）。
4. **edge function 放行 bug**：`netlify/edge-functions/seo-canonical.js` 的 handler 只处理了 passthrough/redirect，`kind:'page'` 会落到末尾 404 分支把正常页面打成 404。改为 `if (kind==='passthrough' || kind==='page') return`。
5. **清理死代码**：删除 `src/seo/updateHead.js`（已被 headConfig 取代）、`scripts/clean-dist.mjs`（不再被 build 引用）。

### 构建门禁（沙箱注意）

- 绕过：构建前设 `CODEBUDDY_SAFE_DELETE_ENABLED=0`（仅沙箱需要，真实 Netlify 部署无此守卫）。
- `vite.config.js` 已设 `build.emptyOutDir:false`（覆盖模式），彻底清理 dist 用 PowerShell `.NET [System.IO.Directory]::Delete` 而非 rm。
